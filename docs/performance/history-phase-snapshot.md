# One verified historical snapshot per performance-validation phase

This protocol is limited to the existing twelve qualification40 comparisons at
base 5f509724da25a2f6ded0c2739a8e7c84bdf59c91. Each validate_current call acquires
a complete private catalog before its body. The preflight and postflight calls
acquire independently. Unknown cohorts, selectors, members, domains, or proof
requests fail closed during a phase; standalone APIs retain their fresh readers.

The catalog expands the original frozen registry and qualification declarations.
Native SHA1 commit, intermediate tree and regular-blob identities bind each
member to its commit, path and mode. Existing SHA256 pins, exact finite edits,
activation markers, producing-input digests, raw report/receipt identities and
complete source-token roles remain independent authorities. The catalog inventory
does not authenticate itself. Complete preflight BASE tree metadata is retained;
unreached legacy baseline, reconstruction and external-read validation paths do
not become new mandatory gates.

All native subprocesses are closed before publication. Input rows come from
the already authenticated finite declarations or native tree edges. Batch-check
declares exact type and size before content accumulation; each batch output is
bounded by those sizes plus framing. A 64 MiB individual-object and 512 MiB
phase-retention resource bound rejects oversized acquisition before content
accumulation. Both stdout and stderr are drained with fixed whole-exchange
deadlines. Incomplete framing, surplus output, nonzero exit, timeout,
cancellation, or cleanup failure prevents publication. Fresh completion checks
reconfirm object availability/type/size and acquisition identities.

The three argv/environment domains remain distinct: plain Git with the original
60-second bound; cumulative Git with its existing command-local safe.directory
and 60-second bound; and quality predecessor Git with its original 30-second
bound. The public runner's base-manifest read retains its existing safe.directory
argv profile and gains a 60-second acquisition bound; its former wrapper had no
local timeout. No global configuration, replacement or security flags are added.

A stable semantic digest binds repository and command-domain identity, original
authority digests, the exact member catalog, native commit/tree graph, object
sizes/digests and typed proof results. Unique phase IDs and preflight/postflight
roles are separate witnesses in the existing smoke receipt. They do not enter
whole-binding equality. Acquisition failures and incomplete postflight cannot
inherit a successful final receipt.

Snapshot backing maps are copied and immutable; member and snapshot records
have slots. A phase lease binds process/thread ownership and is revoked on every
exit. Nested phases reject. Retaining a snapshot or copied context cannot reuse
its capability after the owning phase exits. Returned blob dictionaries are
defensive copies.

Current HEAD/base selectors, freeze-to-HEAD ancestry, physical root/Git/worktree
identity, source/dependency bytes, index/discovery, registry/archive membership,
current-caller equality and every existing owned-read check remain live. The
existing Windows metadata protections remain unchanged. No admission, _freeze,
verify_live or successful current-source decision is cached.

After publication, historical loose/packed objects or historical configuration
may change while the already verified operands remain stable for that phase.
The independent postflight acquisition detects persistent changes observable
then. Retained live Git checks may reject sooner. A transient change restored
between boundaries is not guaranteed detectable. This is a content-addressed,
bounded acquisition with observable boundary checks, not an atomic filesystem
snapshot or continuous historical-store monitoring.

The original CI54 BEFORE map and five borrowed predecessor roles remain exact.
Edited owners already present at that BASE have a disjoint SNAPSHOT_BEFORE
map at the same original BASE; the existing finite transition recipe appends
exact edits while retaining all earlier operations and preimages. CI54-added
owners absent at that BASE retain their absence and are authenticated by
current PINS and the native freeze; no historical preimage is invented. The same existing admission path checks
current pins and caller bytes before historical projection.

The unchanged 180-second complete-command budget includes both acquisitions,
normal validation, witness serialization, real smoke, cleanup and postflight.
The 600-second workload watchdog, 500-second warning, 85% coverage and twelve
behavior shards are unchanged. Focused controls establish their tested
mechanisms only. Complete local and hosted qualification and independent
exact-source reviews remain required; no speedup or full-game certification is
asserted by this contract.

The quality runner creates its validated outside-checkout scratch root inside
the existing supervised operation before launching pytest. A cold task path
therefore supports both collection and four-worker execution without requiring
caller precreation. Existing containment, failure receipts, cancellation and
watchdog behavior remain unchanged. A native checkout control starts with an
absent scratch parent, executes real tmp_path cases on four workers, and passes
the same strict source, dependency, journal and seal validation.
