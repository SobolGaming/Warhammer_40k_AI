# Contract 44.3.24

When Fights First is exhausted, Remaining Combats starts with the player already
owed the next ordinary selection. Inspecting the other player's available units
does not transfer that entitlement. The intentional Remaining-to-Fights-First
restart retains its existing active-player rule.

A Fight pass requires every otherwise-eligible friendly unit to be strictly more
than five inches from every enemy unit, including friendly units outside the
current ordering band. The offer and submission validation use the same current
state predicate. Selectable units and the finite request snapshot remain scoped
to the current band; forced activations cannot pass. A stale offered pass is
rejected before the request queue, accepted history or events change.

Existing finite Fight requests, activation continuations, viewer/event projections
and persistence/replay schemas cover these corrections. No field, decision family
or snapshot conversion is added. Sessions and replays require their producing
runtime; old snapshots are not migrated to the corrected semantics.
