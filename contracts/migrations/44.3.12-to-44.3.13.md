# Contract44.3.13: normal deployment diagnostics during redeployment

Redeploy placement uses normal deployment permissions and geometry, including
Infiltrators outside the owning zone when all models have the ability. The
existing `prebattle_violation` schema adds `infiltrators_keyword_required`,
`infiltrators_enemy_zone_distance`, `infiltrators_enemy_unit_distance`, and
`fortification_deployment_unsupported`. Clients should render these engine
diagnostics and submit a fresh offered retry request as before.

Decision types, request and proposal fields, engine-owned removal/setup events,
persistence shapes, viewer redaction and submission authority remain unchanged.
