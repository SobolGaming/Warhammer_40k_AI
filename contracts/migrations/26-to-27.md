# Contract 26 to 27: same-turn setup and Embark

Order 61 replaces Transport-local same-phase disembark eligibility with canonical
rules-unit setup history for the actual player's turn. Setup through Disembark,
Ingress or repositioned arrival prevents Embark for the remainder of that turn.
Movement remains legal where its own rules allow it. Finite Embark options and
accepted submissions use the same rule. A disembark-specific source exemption
does not exempt other setup kinds.

Phase movement records now require `setup_kind`: a placement-kind token for setup,
or null for a witnessed move. Restore reconstructs it from accepted completion
events and rejects missing, altered or erased history. No legacy value is inferred.
Return-on-death completion events require `active_player_id`, canonical
`unit_instance_id`, and boolean `unit_set_up` evidence. A model returning to a
surviving rules unit does not count as setting up that unit.
Replay advances to `replay-artifact-v21-setup-turn-history`, persistence to
`session-persistence-v19-setup-turn-history`, and metadata and command result/outcome
families to `v27-contract`. Public movement and finite submission envelopes are
unchanged. Setup history remains engine-private.

Only major 27 is supported by this runtime. Retain the 26.x deployment through
at least 2027-09-19 and one released 27.x minor line, whichever is later.
Earlier retention obligations and immutable released baselines remain in force.
