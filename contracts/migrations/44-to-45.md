# Contract 44 to 45

Regenerate clients before connecting to Contract 45. Every error now uses
`error-envelope-v2-diagnostics`; generic errors retain only code and message.
The closed error union permits `diagnostics` only for `proposal_invalid` or
`rule_path_unsupported`. Proposal diagnostics contain `kind: proposal_validation`
and nonempty `violations` with `violation_code` and nullable `field`. Unsupported
diagnostics contain `kind: unsupported_reason` and `reason_code`.

Only the authenticated current-request owner with decision submission authority
receives diagnostics for an uncommitted command. Messages, raw engine objects,
private snapshots, opponent contents and request/context identities are excluded.
No detail is inferred when the staged attempt has none. Authorization denials
remain generic, including another player, coach, spectator or changed journal
authorization context. Authentication and HTTP status classification are unchanged.

HTTP 422 with an error envelope is uncommitted: request, revision, decisions,
events, RNG and authoritative state remain unchanged. Corrected payloads may retry
the same pending request using new command and result identities. HTTP 422 with
a session-command outcome may instead be committed:true, accepted:false; clients
consume the advanced revision and fresh retry request. Command metadata/result/outcome families advance
to v45 because metadata binds the server major. Operator persistence advances to
`session-persistence-v36-contract45` and binds external contract 45.0.0 because
its command journal embeds those response families. Request envelopes and replay
families retain their discriminators; engine state and mutation semantics are
unchanged. Recovery does not reinterpret old journal responses as Contract 45.

The reference server supports one contract major. Retain a separate 44.x deployment
through at least 2027-10-29 and one released 45.x minor line, whichever is later.
Old saves and replay artifacts require their original exact runtime. Earlier
retention obligations and immutable compatibility baselines remain in force.
