# Contract 44.3.32

Shooting declarations select one profile and at most one target per selected
physical weapon copy. Repeating the equipped weapon ID with another profile
returns the existing typed `duplicate_weapon_declaration` diagnostic before
queue pop or authoritative mutation, preserving exact-request retry.
Different copies, models, attached components and legal Firing Deck source
copies remain independently selectable; Hunter restrictions still apply.

Proposal, request, event, viewer, persistence and replay payload shapes remain
unchanged. Exact matching runtime identity remains required. No old-runtime
converter or broader Core, provider, faction or full-game certification is supplied.
