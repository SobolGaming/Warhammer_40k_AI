# Contract 44.3.29

Movement-phase Normal Move, Advance and Fall Back proposals must contain exactly
the current placed physical model inventory of the pending canonical rules unit,
including every living attached component. Wrong inventories return typed
`movement_witness_model_inventory_mismatch` diagnostics on `witness` before the
request is consumed. The same pending request accepts a corrected legal retry.

Existing request, proposal, event, persistence and viewer schemas remain intact.
Well-formed rule-invalid geometry retains its recorded-attempt and fresh-request
retry contract. Runtime identity and generated examples change; exact-runtime
save/load and replay remain required. No prior-runtime compatibility conversion
is supplied. This separately approved prerequisite does not implement D07 or
change terrain permissions, movement budgets, path order or granting sources.
