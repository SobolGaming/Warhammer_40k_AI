# Contract 12 to 13

Contract 13 implements Order 31 / P02D. Every runtime model now carries a
source-linked keyword assignment. Current rules-unit keywords are the union of
its living models and models retained under the existing Fight On Death
presence contract. Ordinary casualties stop contributing immediately; retained
models stop contributing when that retention ends. A surviving component keeps
its datasheet abilities even when a particular model's keyword disappears.

Clients must regenerate their models and consume the new game view and session
projection families. Model display rows require `keywords`, `faction_keywords`,
and `keyword_source_ids`. These fields describe the individual model's intrinsic
identity, including after destruction. Unit display keyword inventories describe
the current rules unit. They must not be reconstructed by unioning every model
row, since a destroyed model can remain in the public roster. Secret formation
membership remains viewer-scoped: before reveal, opponent rows show the original
component roster without revealing attached or split membership.

The catalog accepts exhaustive, source-linked `model_keyword_assignments` for
heterogeneous model profiles. Unscoped catalog keyword declarations apply to all
models; a scoped datasheet must provide every profile and its union must match
the datasheet inventory. Shared stat profiles can carry separate assignments keyed
by existing source-backed `materialization_descriptor_id` values; factories and
datasheet replacement resolve those exact IDs without inspecting model names.
Unknown owners, incomplete scope, duplicate profile/variant pairs,
and malformed assignments fail validation. Runtime payloads require the complete
assignment and cannot infer it from a legacy unit keyword list. Restore verifies
model/source lineage against canonical mustering, splitting, and materialization.

Affected family versions are:

- `game-view-v12-model-keywords`;
- `session-projection-v8-model-keywords`;
- `session-metadata-v13-contract`, `session-command-result-v13-contract`, and
  `session-command-outcome-v13-contract`;
- `session-persistence-v5-model-keywords`, with contract version `13.0.0`.

The existing finite choices and parameterized proposals remain unchanged.
The replay envelope stays `replay-artifact-v8-phase17n-step5a`; its exact engine
build identity rejects incompatible model payloads. Historical 12.x compatibility
baselines remain immutable. The new baseline is `compatibility/13.0.0-shape.json`.

The reference server supports Contract 13 only. Discard cached Contract 12
metadata, projections, and command outcomes. Operators must complete or archive
old sessions on a separately retained 12.x deployment before transferring
service authority. The new server does not negotiate both majors or migrate old
checkpoints. Any previously promised deployment retention windows remain in force.

This change does not implement Order 62's model-specific Warlord or Enhancement
bearer selection and does not certify additional faction gameplay support.
